Политика конфиденциальности

Morpheus (home) — личное приложение одного человека, владельца аккаунта. Других пользователей у него нет.

  • Приложение читает почту, календарь и задачи владельца только по его согласию и только для него самого: сортировка писем, сводка на день, ответы на его вопросы.
  • Данные обрабатываются на домашнем сервере владельца. Они не продаются, не передаются третьим лицам, не используются для рекламы и для обучения чужих моделей.
  • Тексты писем на сервере не хранятся; краткий разбор писем хранится не дольше 90 дней.
  • Доступ можно отозвать в любой момент: Аккаунт Google → Безопасность → Сторонние приложения.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Privacy policy (English)

Morpheus (home) is a personal application used only by its owner. It has no other users.

  • With the owner's consent, it reads the owner's mail, calendar and tasks solely to serve the owner: sorting mail, a daily summary, answering the owner's questions.
  • Data is processed on the owner's home server. It is not sold, shared with third parties, used for advertising, or used to train third-party models.
  • Message bodies are not stored; short message summaries are kept for no more than 90 days.
  • Access can be revoked at any time: Google Account → Security → Third-party apps.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
